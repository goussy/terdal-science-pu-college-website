# Shivagangaa Terdal International School Website

This is a standalone HTML/CSS/JS version designed to run directly from Windows File Explorer.

## Run
Double-click `index.html`.

For best results, use VS Code + Live Server, or a local server:
`python -m http.server 5500`

Then open `http://localhost:5500`.

## Important
The supplied logo says "Shivagangaa Terdal International School", while the original brief referred to "Terdal Public School". Confirm the official name before deployment.

School details marked with [Verified ...] or [Official ...] are intentionally placeholders and must be replaced with client-provided information.

The gallery currently uses temporary remote image placeholders. Replace them with the school's real photographs before production.

## Folder
- index.html: homepage
- about.html, academics.html, admissions.html, facilities.html, activities.html, achievements.html, gallery.html, news.html, contact.html
- privacy-policy.html, terms.html, 404.html
- styles.css: centralized theme and responsive design
- script.js: navigation, reveal animation, forms, gallery/lightbox
- assets/logo.webp: supplied school logo


## IMPORTANT FOR WINDOWS
Extract the ZIP using **Extract All** before editing. This standalone version also embeds CSS, JavaScript and the logo inside every HTML page, so `index.html` works even when opened directly as a local file.
